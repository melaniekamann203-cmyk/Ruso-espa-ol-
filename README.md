# Ruso ⇄ Español

Guía bilingüe para leer ruso (hispanohablantes) y leer español (rusohablantes): alfabeto con sonidos, reglas de lectura y prompts de traductor listos para copiar.

Двуязычный гид: читать по-русски для испаноговорящих и читать по-испански для русскоговорящих.

Abrir / Открыть: https://melaniekamann203-cmyk.github.io/ruso-espa-ol-/ (versión rusa: agregar `#ru`)
